쇼핑몰 필요 페이지 목록
========================

1. 메인 페이지 (홈)
   - 배너/슬라이더
   - 추천 상품
   - 카테고리 바로가기
   - 신상품/베스트셀러

2. 상품 목록 페이지
   - 카테고리별 필터
   - 가격/인기순 정렬
   - 페이지네이션

3. 상품 상세 페이지
   - 상품 이미지 갤러리
   - 가격/옵션 선택
   - 상품 설명
   - 리뷰/평점
   - 장바구니 담기 버튼

4. 장바구니 페이지
   - 담긴 상품 목록
   - 수량 변경/삭제
   - 총 금액 계산

5. 주문/결제 페이지
   - 배송지 입력
   - 결제 수단 선택
   - 주문 요약

6. 주문 완료 페이지
   - 주문 번호
   - 주문 내역 확인

7. 회원가입 페이지
   - 이메일/비밀번호
   - 이름/연락처/주소

8. 로그인 페이지
   - 이메일/비밀번호 로그인
   - 소셜 로그인

9. 마이페이지
   - 주문 내역
   - 회원 정보 수정
   - 배송지 관리
   - 찜 목록

10. 검색 결과 페이지
    - 키워드 검색 결과
    - 필터/정렬

11. 고객센터 페이지
    - FAQ
    - 1:1 문의

12. 이용약관 / 개인정보처리방침 페이지


================================
어드민 페이지
================================

13. 어드민 대시보드
    - 매출 현황/통계
    - 신규 주문 알림
    - 오늘의 요약 (주문수, 매출, 신규회원)

14. 상품 관리 페이지
    - 상품 목록 (검색/필터)
    - 상품 등록/수정/삭제
    - 카테고리 관리
    - 재고 관리

15. 상품 등록/수정 페이지
    - 상품명/가격/설명 입력
    - 이미지 업로드
    - 옵션/변형 설정
    - 카테고리 선택

16. 주문 관리 페이지
    - 주문 목록 (상태별 필터)
    - 주문 상태 변경 (결제확인/배송중/배송완료)
    - 일괄 처리

17. 주문 상세 페이지
    - 주문 정보 (상품/수량/금액)
    - 주문자/배송지 정보
    - 결제 정보
    - 배송 추적
    - 주문 상태 변경

18. 회원 관리 페이지
    - 회원 목록 (검색/필터)
    - 회원 상세 정보
    - 주문 이력 조회

19. 배너/콘텐츠 관리 페이지
    - 메인 배너 등록/수정
    - 팝업 관리

20. 리뷰 관리 페이지
    - 리뷰 목록
    - 리뷰 승인/삭제

21. 문의 관리 페이지
    - 1:1 문의 목록
    - 답변 작성

22. 매출/통계 페이지
    - 기간별 매출 차트
    - 상품별 판매 순위
    - 회원 가입 추이
